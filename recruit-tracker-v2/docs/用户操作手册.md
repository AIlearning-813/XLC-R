## 1. 快速入门

### 1.1 系统访问

在浏览器中打开系统地址，进入登录页面。

### 1.2 登录

- 输入管理员分配的**账号**和**密码**
- 点击"登录系统"按钮
- 登录成功后自动跳转到工作台
- 系统会记住登录状态，**24 小时内无需重复登录**

> ⚠️ 连续输错密码 5 次，账号将被锁定 15 分钟。

### 1.3 界面布局

```
┌──────────────────────────────────────┐
│  顶部导航栏      [用户名] [退出]      │
├────────┬─────────────────────────────┤
│ 侧边栏  │                         │
│ 工作台   │      主内容区域           │
│ 招聘需求 │                         │
│ 录入简历 │                         │
│ 招聘看板 │                         │
│ 候选人   │                         │
│ 数据分析 │                         │
│ ...     │                         │
├────────┴─────────────────────────────┤
│  底部状态栏                          │
└──────────────────────────────────────┘
```

- **侧边栏**：点击菜单切换功能模块
- **顶部导航栏**：显示当前页面标题
- **主内容区域**：当前功能页面内容

## 2. 工作台

工作台是登录后的首页，展示招聘工作全局概览。

### 2.1 功能区块

| 区块 | 说明 |
|------|------|
| **时间段指标卡片** | 今日/本周/本月的关键数据：新候选人、面试安排、Offer 发放、入职人数 |

- ⚠️ **简历解析失败**：需要手动录入
- 🔔 **系统告警**：邮箱扫描异常等（仅管理员）

## 3. 招聘需求管理

招聘需求是招聘工作的起点——先有需求，再有候选人录入和管道流转。

### 3.1 需求列表

路径：侧边栏 → **招聘需求**

- **列表视图**：表格形式展示所有需求
- **状态筛选**：待审批 / 招聘中 / 已完成 / 已关闭

### 3.2 新建需求

路径：招聘需求页 → 点击"新建需求"按钮

1. 填写需求标题
2. 选择归属部门（四级部门树）
3. 填写招聘人数、到岗时间、招聘周期
4. 设置优先级（高/中/低）
5. 选择岗位类型
6. 提交 → 管理员审批

### 3.3 需求状态流转

```
待审批 → 招聘中 → 已完成 → 已关闭
          ↓
        已关闭（提前终止）
```

## 4. 简历录入

系统支持两种录入方式：**手动上传简历文件** + **邮箱自动归集**。

### 4.1 上传简历录入

路径：侧边栏 → **录入简历**

**五步流程**：

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1. 上传文件 | 拖拽或点击上传 | 支持 PDF/Word/图片/TXT/HTML/RTF 等 15 种格式 |
| 2. 提取文本 | 自动 | 系统调用腾讯云 OCR + 文本提取 |
| 3. AI 解析 | 自动 | DeepSeek AI 结构化提取姓名/电话/邮箱/工作经历/教育背景 |
| 4. 核对修正 | 手动 | 检查 AI 提取结果，修正错误，补充遗漏 |
| 5. 确认创建 | 手动 | 选择关联岗位，创建候选人档案 |

> 💡 **去重检测**：系统会自动检查手机号/邮箱/姓名是否与已有候选人重复，避免重复录入。

### 4.2 邮箱自动归集

参见 [第 9 章：邮箱自动归集配置](#9-邮箱自动归集配置)。

## 5. 招聘看板（核心）

招聘看板是系统的核心交互模块，采用 **Kanban（看板）风格**。

路径：侧边栏 → **招聘看板**

### 5.1 看板布局

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 筛选通过  │  邀约    │  初试    │  复试    │  终试    │ ...
│ 3人      │ 2人      │ 1人      │ 1人      │          │
│ ┌──────┐ │ ┌──────┐ │ ┌──────┐ │ ┌──────┐ │          │
│ │ 张三  │ │ │ 李四  │ │ │ 王五  │ │ │ 赵六  │ │          │
│ └──────┘ │ └──────┘ │ └──────┘ │ └──────┘ │          │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

### 5.2 12 步漏斗阶段

| 阶段 | 含义 | 说明 |
|------|------|------|
| 1. 筛选通过 | 简历初筛通过 | 简历符合基本要求 |
| 2. 邀约 | 发出面试邀请 | 已联系候选人 |
| 3. ✨ 已确认面试 | 候选人确认参加 | 可选节点，手动标记 |
| 4. 初试 | 第一轮面试 | 通常 HR 初面 |
| 5. 复试 | 第二轮面试 | 业务部门面试 |
| 6. 终试 | 最终面试 | 高管面/终面 |
| 7. Offer | 发出录用通知 | 已发 Offer |
| 8. 入职 | 候选人入职 | 已报到 |
| 9. 已通过 | 试用期通过 | 正式录用 |
| 10. 淘汰 | 公司淘汰 | 5 种淘汰原因可选 |
| 11. 放弃 | 候选人放弃 | 8 种放弃原因可选 |

### 5.3 看板操作

#### 拖拽流转

- **拖拽候选人卡片**到目标阶段列，即可完成阶段流转
- 系统自动校验流转合法性（不可跳回、不可倒流）
- 跳阶段会自动回填中间节点时间

#### 快速操作

- **点击候选人卡片** → 查看详情
- **选中候选人 + 快捷键** → 快速流转（参见 [快捷键速查](#11-快捷键速查)）
- **批量选择** → 勾选多个候选人 → 使用浮现操作栏批量操作

### 5.4 岗位切换

看板顶部有岗位选择器，切换岗位查看不同岗位的看板数据。

## 6. 候选人管理

### 6.1 候选人列表

路径：侧边栏 → **候选人**

**三个 Tab**：
| Tab | 说明 |
|-----|------|
| 活跃候选人 | 当前在管道中的候选人 |
| 已结束 | 已被淘汰/放弃的候选人 |
| 待分配 | 邮箱自动归集录入的候选人（尚未分配岗位） |

**功能**：
- 搜索：按姓名/电话/邮箱搜索
- 筛选：按岗位/阶段/来源/日期筛选
- 分页：支持大数据量分页浏览
- 批量操作：批量流转阶段、批量分配岗位、批量导出 CSV

### 6.2 候选人详情

点击候选人进入详情页，包含：

| 区块 | 内容 |
|------|------|
| **基本信息** | 姓名、电话、邮箱、学历、工作年限、当前岗位 |
| **简历预览** | PDF/DOCX/图片在线预览 |
| **工作经历** | AI 解析的结构化工作经历 |
| **教育背景** | 学历、学校、专业 |
| **沟通记录** | 电话/邮件/微信/短信/面谈记录，含方向标注（呼出/呼入） |
| **审计日志** | 所有操作的历史记录（谁在什么时间做了什么） |
| **关联需求** | 查看/关联招聘需求 |

### 6.3 沟通记录

在候选人详情页可添加沟通记录：
- **沟通方式**：电话 / 邮件 / 微信 / 短信 / 面谈
- **方向**：呼出（你联系候选人）/ 呼入（候选人联系你）
- **内容**：沟通摘要
- **跟进时间**：设置下次跟进提醒

## 8. AI 招聘助手

路径：侧边栏 → **AI 助手**

### 8.1 功能说明

AI 招聘助手基于 **RAG（检索增强生成）** 技术：
1. 理解你的问题意图
2. 从公司知识库检索相关信息
3. 结合公司人设（CompanyProfile）和检索结果
4. 由 DeepSeek AI 生成回答

### 8.2 使用方式

- **自由提问**：在输入框输入问题，按 Enter 发送
- **快捷问题**：点击预设的快捷问题，快速获得答案
- **引用来源**：AI 回答会标注引用了哪些知识库条目
- **反馈**：对 AI 回答进行 👍/👎 反馈，帮助系统改进

### 8.3 典型使用场景

| 场景 | 示例问题 |
|------|----------|
| 招聘话术 | "请给我一段电话邀约的话术" |
| 公司介绍 | "介绍一下公司的薪酬福利" |
| JD 参考 | "高级销售经理的 JD 模板" |
| 面试题库 | "有哪些适合考察沟通能力的面试题" |
| 行业对比 | "我们公司和竞品在薪资方面有什么优势" |

## 9. 邮箱自动归集配置

### 9.1 功能说明

系统可以自动扫描指定邮箱（如 HR 招聘邮箱），从 BOSS 直聘、智联招聘等平台的通知邮件中提取候选人简历附件，自动录入系统。

### 9.2 配置步骤

路径：侧边栏 → **系统设置** → **邮箱配置** Tab

1. **添加邮箱**
   - 点击"添加邮箱"
   - 选择邮箱类型（QQ邮箱 / 163邮箱 / 企业邮箱 / 其他）
   - 系统自动填充 IMAP 服务器和端口
2. **填写授权码**
   - QQ邮箱：登录 QQ邮箱 → 设置 → 账户 → POP3/IMAP 服务 → 生成授权码
   - 163邮箱：登录 163邮箱 → 设置 → POP3/SMTP/IMAP → 新增授权码
   - ⚠️ 不是邮箱密码，是**授权码**！
3. **测试连接**
   - 点击"测试连接"按钮
   - 验证 IMAP 连接是否成功
4. **启用自动扫描**
   - 开启"启用"开关
   - 系统每 **30 分钟** 自动扫描一次未读邮件

### 9.3 安全说明

- 授权码使用 **AES-256-GCM** 加密存储
- 密钥和盐值分离存放在云函数环境变量中
- 前端不会接触到加密密钥
- 支持在线密钥轮换

### 9.4 手动扫描

在邮箱配置页点击"手动扫描"按钮，立即触发一次扫描。

## 12. 知识库管理

### 12.1 什么是知识库

知识库是 AI 招聘助手的"大脑"。AI 回答问题时，会从知识库中检索相关信息，结合公司人设生成准确、符合公司调性的回答。

### 12.2 9 种知识分类

| 分类 | 内容示例 | 用途 |
|------|----------|------|
| 🏢 公司介绍 | 公司历史、规模、业务 | AI 回答"公司是做什么的" |
| 🎨 企业文化 | 价值观、使命、工作氛围 | AI 回答"公司文化怎么样" |
| 💰 薪酬福利 | 薪资结构、福利待遇 | AI 回答"薪资福利如何" |
| 📞 招聘话术 | 电话邀约话术、邮件模板 | AI 生成邀约话术 |
| 📋 JD 模板 | 各岗位标准 JD | AI 生成 JD 参考 |
| 🎯 面试题库 | 行为面试题、技术面试题 | AI 推荐面试题目 |
| 📊 行业知识 | 教育行业动态、趋势 | AI 回答行业相关问题 |
| 🔍 竞品分析 | 竞争对手信息、对比 | AI 回答竞品相关问题 |
| 📜 政策法规 | 劳动法、招聘相关法规 | AI 回答合规问题 |

### 12.3 管理知识条目

路径：系统设置 → **知识库** Tab

- **新增**：手动录入标题、内容、分类、标签
- **编辑**：修改已有条目
- **搜索**：按关键词、分类、标签搜索
- **审核**：AI 自动生成的草稿需管理员审核后才能被 RAG 检索
- **归档**：过时条目可归档，不会被 RAG 检索
- **引用计数**：被 AI 引用次数多的条目自动排前

### 12.4 AI 自动生成知识

系统可通过 **web-search-agent** 云函数从网络搜索公司相关信息，自动生成知识库草稿。人工审核后方可生效，确保信息准确性。

## 13. 管理员专属功能

以下功能仅**管理员**角色可见：

### 13.1 变更审核

路径：侧边栏 → **变更审核**

招聘专员对岗位（Job）和系统配置（Config）的增删改操作，需要管理员审批：

1. 查看待审核的变更列表
2. 对比变更前后的内容（before/after 对比视图）
3. 选择"通过"或"驳回"
4. 审批通过后变更生效

> 📌 候选人操作不经过审批，通过审计日志追溯。

### 13.2 历史数据导入

路径：侧边栏 → **历史导入**

支持从 CSV/Excel 批量导入历史招聘数据：

**四步向导**：
1. **上传文件**：选择 CSV 或 Excel 文件
2. **列映射**：将文件列对应到系统字段
3. **去重策略**：选择重复数据处理方式（跳过/覆盖/全部导入）
4. **确认导入**：预览结果并确认

### 13.3 回收站

路径：侧边栏 → **回收站**

被删除的候选人进入回收站（软删除），可以：
- **恢复**：候选人回到活跃列表，关联数据一并恢复
- **永久删除**：彻底清除，不可恢复（需二次确认）

### 13.4 数据移交

当招聘专员离职或调岗时，管理员可将其负责的候选人数据移交给其他专员。

路径：系统设置 → **系统配置** Tab → 数据移交

### 13.5 部门管理

路径：系统设置 → **部门管理** Tab

管理公司四级部门树（部门 → 中心 → 组 → 岗位）。

### 13.6 系统健康监控

管理员工作台额外显示系统健康状态面板：
- 数据库可用性
- 云存储状态
- 云函数运行状态
- API 余额预警

## 14. 常见问题

### Q1：为什么登录后直接跳到了工作台而不是登录页？

系统在 24 小时内会记住登录状态，无需重复登录。如需要切换账号，请点击侧边栏底部的"退出登录"。

### Q2：上传简历后解析失败怎么办？

1. 检查文件格式是否支持（PDF/Word/图片/TXT 等）
2. 文件是否加密或损坏
3. 如果 AI 解析失败，可以手动填写候选人信息
4. 点击通知中心的失败通知可查看失败原因

### Q3：为什么候选人拖拽不过去？

1. 检查流转是否合法（不能跳过关键阶段、不能倒流）
2. 如果岗位设置了面试轮次要求，需要满足轮次条件
3. 部分阶段需要先标记"已确认面试"

### Q4：邮箱扫描不到新简历？

1. 检查邮箱是否已启用（开关是否为开启状态）
2. 点击"测试连接"确认 IMAP 连接正常
3. 确认招聘平台的通知邮件确实发送到了该邮箱
4. 授权码是否过期（QQ邮箱授权码有效期通常为长期，但可能被手动失效）
5. 查看最近扫描时间，30 分钟内不会重复扫描

### Q5：知识库的条目为什么 AI 搜不到？

1. 条目状态必须是"已发布"（不是"草稿"或"已归档"）
2. AI 会根据问题意图匹配合适的分类，检查条目的分类是否正确
3. 条目需要有足够的标签和关键词

### Q6：如何修改密码？

点击侧边栏底部的密码图标，输入旧密码和新密码（8位以上）即可修改。

### Q7：忘记密码怎么办？

联系管理员在后台重置密码。

### Q8：手机/平板能用吗？

系统支持移动端访问（宽度小于 768px 自动切换为移动端布局）：
- 侧边栏变为可滑出的抽屉菜单（点击左上角汉堡图标）
- 看板视图自动切换为列表视图
- 详情页全屏显示
- 拖拽操作改为下拉选择
